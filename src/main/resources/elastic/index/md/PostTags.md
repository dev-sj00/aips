# 엘라스틱 서치 품사 태그(POS Tags) 가이드

한국어 형태소 분석에 사용되는 품사 태그 설명서  
출처: https://esbook.kimjmin.net/06-text-analysis/6.7-stemming/6.7.2-nori#request-5
---

## 어미 (Ending)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **EC** | 연결 어미 | 문장을 연결 | 먹고, 가서, 읽으면 |
| **EF** | 종결 어미 | 문장 종결 | 먹는다, 가니?, 와라 |
| **EP** | 선어말 어미 | 시제/높임 표현 | 먹었다, 먹겠다, 먹시다 |
| **ETM** | 관형형 전성 어미 | 명사 수식 형태 | 먹는 음식, 간 사람 |
| **ETN** | 명사형 전성 어미 | 명사 형태로 전환 | 먹기, 가기, 함 |

## 접사 (Affix)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **XSA** | 형용사 파생 접미사 | 형용사 생성 | 사랑스럽다, 믿음직하다 |
| **XSV** | 동사 파생 접미사 | 동사 생성 | 생각하다, 공부시키다 |

## 조사 (Particle)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **JKB** | 부사격 조사 | 장소/수단 표현 | 학교에, 친구와, 연필로 |
| **JKC** | 보격 조사 | 보어 형성 | 선생님이 되다 |
| **JKG** | 관형격 조사 | 소유 표현 | 나의, 친구의 |
| **JKO** | 목적격 조사 | 목적어 표시 | 밥을, 책을 |
| **JKQ** | 인용격 조사 | 인용 표현 | 간다고, 예쁘다고 |
| **JKS** | 주격 조사 | 주어 표시 | 나는, 철수가 |
| **JKV** | 호격 조사 | 부름 표현 | 철수야, 선생님이시여 |
| **JX** | 보조사 | 의미 추가 | 만, 도, 까지, 조차 |
| **JC** | 접속 조사 | 나열/선택 | 과, 와, 이나, 하고 |

## 수식언 (Modifier)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **MAG** | 일반 부사 | 용언 수식 | 매우, 잘, 빨리, 천천히 |
| **MAJ** | 접속 부사 | 문장 연결 | 그러나, 그리고, 하지만 |
| **MM** | 관형사 | 체언 수식 | 새, 헌, 모든, 각 |
| **IC** | 감탄사 | 감정/응답 표현 | 아, 오, 네, 예 |

---

## 용언 (Predicate)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **VA** | 형용사 | 상태/성질 표현 | 예쁘다, 크다, 좋다 |
| **VV** | 동사 | 동작 표현 | 먹다, 가다, 보다 |
| **VCP** | 긍정 지정사 | "이다" | 학생이다 |
| **VCN** | 부정 지정사 | "아니다" | 학생이 아니다 |
| **VX** | 보조 용언 | 본동사 보조 | 먹어 버리다, 가고 있다 |

## 기호 (Symbol)

| 태그 | 이름 | 예시 |
|------|------|------|
| **SC** | 구분자 | , (쉼표) |
| **SE** | 줄임표 | … (말줄임표) |
| **SF** | 마침표/물음표/느낌표 | . ? ! |
| **SH** | 한자 | 韓國, 大學 |
| **SL** | 외국어 | English, Hello |
| **SN** | 숫자 | 123, 4.5 |
| **SP** | 공백 | (띄어쓰기) |
| **SSC** | 닫는 괄호 | ) ] } |
| **SSO** | 여는 괄호 | ( [ { |
| **SY** | 기타 기호 | @, #, $, % |

---

## 명사 (Noun)

| 태그 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **NA** | 분석 불능 | 미등록어 | 알 수 없는 단어 |
| **UNA** | 분석 불능 (명사) | 명사로 추정 | 신조어, 고유명사 |
| **UNKNOWN** | 미분류 | 분류 불가 | 특수 케이스 |
